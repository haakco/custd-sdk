# SDK 3.43.2: native bundle column locations

JavaScript capture and the Go relay now preserve legitimate Hermes/Metro column offsets above one million, up to the standard signed 32-bit maximum. Line numbers retain their one-million bound; private content, frame counts and envelope limits are unchanged.

The shared relay fixture uses a 6.3 MB bundle location. Focused JavaScript/Go regressions prove preservation, the maximum column bound and the retained line bound. This release also includes the 3.43.1 fix for existing URL-safe Site keys and corrects the tenant-finalization documentation.
