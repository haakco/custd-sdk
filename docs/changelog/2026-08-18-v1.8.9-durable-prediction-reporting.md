# Custd SDK v1.8.9

Version 1.8.9 reconciles the durable Python queue preparation with the
prediction administration helpers from the public v1.8.7 history and the
report-export lifecycle clients from v1.8.8.

## Durable selective queue — Python

The Python SDK now ships a crash-safe, file-backed event queue with selective
ack semantics. Queued events are persisted through an atomic private JSON
replacement (`mkstemp` + `fsync` + directory `fsync` + `os.replace`), so event
UUIDs survive a process restart or power loss. File-size and in-memory queue
limits raise `QueueFullError` instead of silently dropping events. When a
batch is partially accepted, only rejected UUIDs remain queued for retry.

The default remains `MemoryQueueStorage` with `max_queue_size=1000`. Opt in
with `FileQueueStorage(path, max_bytes=...)` or the equivalent `queue.path`
configuration. Queue storage remains intentionally asymmetric: Go and
TypeScript retain their in-memory queues, Python provides the opt-in durable
storage, and PHP retains its existing `FileQueueStore`.

## Prediction administration — all SDKs

Go, TypeScript, Python, and PHP expose tenant-scoped configurable signal
prediction helpers for definitions, immutable versions, pull and push
sources, run history, outcomes, evaluation, threshold events, and lifecycle
actions. Every request carries the company slug and preserves the server's
bounded snake-case contract.

## Report-export lifecycle — all SDKs

Go, TypeScript, Python, and PHP expose tenant-scoped report-export lifecycle
methods to create, list, inspect, cancel, and download exports through
authenticated API routes. Downloads are bounded to 64 MiB and lifecycle
identifiers are validated before requests leave the client; storage keys,
provider URLs, and infrastructure authority are never returned to callers.

The generated TypeScript distribution artifacts and all synchronized package
version manifests are included in this release preparation. Python continues
to use the existing git subdirectory install path; no new PyPI mirror is
opened.
