# v3.68.0 — typed closed values, streamed downloads, realm fields that keep

The operation snapshot is resynced from local Custd. It reads the published contract files: the two
OpenAPI files and `api-operations.json`. All 637 required operations are covered by Go, TypeScript,
Python, PHP and Rust.

This release breaks public shapes on purpose. Custd is pre-live.

## Closed string sets are typed (Go, Python, PHP)

TypeScript did this in 3.66.0. Every closed set the API declares is now typed in the other SDKs too. A
value Custd adds later still decodes in every SDK; nothing rejects an unknown value on read.

- **Go:** 141 new named string types with constants, on response fields, request fields and closed
  query or path parameters.
  - Names follow TypeScript: `BrowserIdentityMode`, `SubjectExportStatus`, `ClientBootstrapState`.
  - Reporting-pack unions and `SiteAIProduct` no longer reject unknown values on decode. Call
    `.Valid()` to check membership.
  - **Breaking:**
    - String variables, `[]string` roles or formats, and values compared through `any` or maps need
      the typed constants or `string(...)`.
    - Changed signatures: `AdminUsers.Update` and `Enable`, `SubjectExports.Download`,
      `Audit.ExportEvents`, `NotificationDestinations.Get` and `Put`, `UncertaintyModels.List`, plus
      `ErrorIssueListOptions`, `AdminSiteReportOptions` and `AdminSiteSearchRowsQuery`.
- **Python:** 178 new `typing.Literal` aliases exported from `custd`, 209 in all. Module constants carry
  their alias.
  - The check is type-level only. Time-plan views no longer reject unknown basis, severity or
    annotation values.
  - `decode` now resolves types a module imports only for type checking, so the shared site report
    decodes.
  - `OffboardingState` moved to `custd.client` and `SearchPoolAccess` to
    `custd.admin_site_search_pool`. Both are still exported from `custd`.
- **PHP:** every closed set is a final class of named constants, such as `SiteCheckMode::PAUSED`. DTO
  properties and parameters carry its PHPStan type (`SiteCheckMode::*`). Values stay strings at
  runtime.
  - **Breaking:** the backed enums that held server values are now constants classes. Use the
    constants and plain strings instead of cases, `->value`, `::from()` and `::cases()`. Examples
    include `SiteCheckMode`, `SiteSearchProvider`, `SiteAIMode`, `SiteRule` and
    `Provisioning\ProducerReservationStatus`.
  - **Breaking:** duplicate constant groups on DTOs and clients are removed in favour of the owning
    class. For example, `AuthProjectClient::IDENTITY_ISOLATED` is now
    `AuthProjectIdentityMode::ISOLATED`, and `SiteReport::TEMPLATE_FULL` is now
    `SiteReportTemplate::FULL`.

## Realm apply keeps what it leaves out (all SDKs)

Custd now keeps an auth-project realm field that an apply leaves out or sends as `null`. `""` or `[]`
clears it, and `loginPaused` is set only when sent. The fields are `entryPath`, `brandAccent`,
`signInMethods`, `profileFields` and `loginPaused`.

- **Go:** `EntryPath` and `BrandAccent` are `*string`, and `LoginPaused` is `*bool`.
- **Rust:** these fields are `Option`s.
- **Python:** they are `NotRequired`. Status reads use `AuthProjectStoredDesiredState`.
- **TypeScript:** they are optional. Status reads use `AuthProjectConfiguredState`.
- **PHP:** `DesiredState` sends `""` and `[]`, so a caller can clear these fields, and leaves out
  `null`. `loginPaused` is `?bool`.

## Streamed downloads (all SDKs)

The offboarding bundle and the audit export stream into a caller's writer instead of being held in
memory. Each returns the content type and request id. The offboarding download also returns its
verified length and SHA-256.

- **Go:** `Offboarding.Download(ctx, uuid, w)` and `Audit.ExportEvents(..., w)`.
- **TypeScript:** `offboarding.downloadStream()`. `audit.exportEvents()` now returns a stream.
- **Python:** `offboarding.download(uuid, writer)` and `audit.export_events(writer, ...)`.
- **PHP:** `download($uuid, $sink)` and `exportEvents($sink, ...)`. Both return `StreamedDownload`.
- **Rust:** `download_offboarding(uuid, sink)` and `export_audit_events(..., sink)`.

The buffered versions and their 64 MiB cap are gone.

## Shapes corrected to the server

- **Site Insights:** these fields are now values the server always sends, in every SDK.
  - The fields: rankings `pool`, search pool `termsVersion`, page `shareImage`, `densityPercent`,
    `sharedPercent`, Lighthouse `url` and `pages`, and report `template`.
  - Saving a keyword list sends `marketSampleEnabled`.
  - Go `DensityPercent` and `SharedPercent` are values, not pointers.
- **Email relay:** the view's `relay` is null when the tenant uses Custd's own relay.
- **Audit:** list and export accept `environmentId`.
- **Always-sent fields:** these are now required.
  - Producer reservation `childCompanySlug` and `maxTtlSeconds`
  - Rollup provenance `tenantSlug`
  - Time plan `description`, and a stored definition's `redistributionMode` and `autoAdvance`
  - `AdminSite.environment`
  - `MeasurementProject.description`
- **Prepared-output queries:** a stored query document can be sent verbatim. Go uses
  `Reporting.QueryOutputDocument`, PHP `ReportingQueryDocument`, Python any mapping, and Rust any
  `Serialize`.
- **Go nullable fields:** these are now pointers.
  - Email relay
  - Estimate chance and movement, and story `MovementDays`
  - Exception `handled`
  - Measurement project `Description` and `DefinitionOfDone`, which can now be cleared with `""`
- **Go request ids:** measurement, reporting, analytics and parser calls now record the request id.
- **Go prepared-data reads:** these are on `Reporting` only. The duplicate `PreparedDataClient` read
  methods are removed.
- **TypeScript:** `AuthProjectDomainConvergence` includes `rolling-out`.

## Contract sync without a person

`scripts/sync-api-contract.py --source` reads a URL or a directory. `just sync-api-contract` defaults to
`https://custd.com/docs/openapi`. An hourly workflow, "API Contract Sync", opens or updates one pull
request when the published contract changes.
