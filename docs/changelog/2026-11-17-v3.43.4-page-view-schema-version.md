# v3.43.4: page views follow the Site's schema version

The browser script tag always sent `page-view` events as schema `1.0.0`, so a tenant that
moved its page-view schema to a newer version had every script-tag page view refused, with no
way to change the embed. The Site configuration the script already fetches now carries
`pageViewSchemaVersion`, and the script sends page views with it. Other event types keep
`schemaVersion`. A missing or malformed value falls back to the default.

`createBrowserTracker` accepts the same `pageViewSchemaVersion` option.
