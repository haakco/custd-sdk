# v3.73.0 — React site monitoring templates

- `SiteUptimePanel` loads uptime history and provides uptime windows, daily uptime,
  response times, range selection, and retry.
- `DailyUptimeChart` and `UptimeResponseChart` can also render independently.
- `SiteLighthousePanel` shows the latest desktop and mobile scores.
- `SiteStatusPageView` shows public service state and published updates.

Use application CSS, custom labels, and formatters to fit each template to the
host site. See the [site monitoring guide](../../README.md#site-monitoring-templates).
