# v3.72.1 — issuer inspection accepts a trailing slash

## Fixes

- **Go `Admin.InspectIssuer`** accepted an issuer only when its discovery document named it without a trailing
  slash. Ory Hydra publishes `https://auth.custd.com/`, so `custdctl system doctor` reported the issuer and its
  signing keys as failed against a healthy issuer. The published identifier is now compared without the slash.

No other SDK has issuer inspection; the other packages change only their version.
