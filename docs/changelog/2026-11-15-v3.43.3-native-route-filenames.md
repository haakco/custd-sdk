# v3.43.3: native route filenames

Native error capture preserves Vike `+Page.tsx` and Expo `[id].tsx` basenames,
including percent-encoded route names beneath Expo group directories. Decode only
extracted basenames; reject encoded separators, query characters and account markers.
PHP applies the same bounded basename rule. Full URLs, paths and messages remain excluded.

The shared relay fixture also retains real Hermes columns above six million.
Line bounds and signed 32-bit column bounds are unchanged.
