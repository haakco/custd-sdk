# Custd SDK v1.8.3

Version 1.8.3 combines the client data lifecycle SDK surfaces from v1.8.0 with
the browser tracker module-installer correction.

The browser script now resolves and passes its own module script element when
`document.currentScript` is unavailable for ES modules. This allows the hosted
tracker to read `data-site-uuid` and `data-write-key` reliably.

The documented hosted asset path is `/custd-sdk/browser-script.js`.

This patch also corrects the lifecycle documentation formatting gate found
after the immutable v1.8.1 release was published.

Mirror publication now targets the maintained containerd ARC runner instead
of waiting indefinitely for the retired generic runner label.
