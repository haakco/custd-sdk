# Custd SDK v1.8.8

Version 1.8.8 adds tenant-scoped executive report export lifecycle methods to
the Go, TypeScript, Python, and PHP SDKs. Clients can create, list, inspect,
cancel, and download report exports through authenticated API routes without
receiving storage object keys, provider URLs, or infrastructure authority.

Downloads are bounded to 64 MiB and lifecycle identifiers are validated before
requests leave the client. This release also includes the prediction admin
helpers prepared after v1.8.6, generated TypeScript distribution artifacts,
and synchronized package versions.
