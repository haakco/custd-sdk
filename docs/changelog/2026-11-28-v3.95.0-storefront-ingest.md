# SDK 3.95.0 storefront and ingest contracts

- PHP, Python and Rust expose storefront offers, carts, quotes, checkout, purchases, payment and
  credit notes through the credential-scoped Billing API. All five SDKs test those 11 operations
  against the same snapshot.
- All five SDKs support Admin purchase-handoff credential management and campaign revision preview.
- Go and JavaScript cover the 719 application operations in the snapshot. PHP covers 670, while
  Python and Rust cover 667 each. The remaining operations are Billing.
- The Ingest snapshot records 16 explicit GET and POST operations. Both MCP transport entries are
  excluded from SDK application operation coverage.
