# v3.69.0 — one Go transport, real zeros kept, site remedies decode everywhere

This release breaks the Go custom transport on purpose. Custd is pre-live.

## Go

- **Custom transport:** a custom `ClientConfig.HTTPClient` is now any `Do(*http.Request) (*http.Response, error)`,
  such as an `*http.Client`. `HTTPRequest` and `HTTPResponse` are removed. Every call goes through that one
  transport. Downloads stream through it, and the request context reaches it.
  - With a custom client, the `APIKey` header is still sent. The OAuth client-credentials settings are not
    used.
  - Header names reach the transport in canonical form.
  - The built-in path now sends the client and command audit labels on every admin request.
- **Download timeouts:** offboarding bundles, audit exports and usage exports no longer stop after 10 seconds.
  They fail only if the response headers, or the next bytes, take more than 30 seconds. JSON calls keep the
  10-second limit.
- **Domain bindings:** every auth-project domain route returns one `AuthDomainBinding`, so
  `AuthProjectDomainBinding` and its nested types are removed. `DNSProof` is nil for a minted hostname.
- **Real zeros kept:**
  - `UncertaintyBoundInput.Value` is now `*float64`.
  - `PresentationPoint.Value`, `LowerValue` and `UpperValue`, and `PresentationReference.Value`, are now
    `*float64`.
- **Typed fields:** `AdminSiteCreate.IdentityMode` is now `BrowserIdentityMode`, and `TimePlanTransition.Type`
  is now `TimePlanCommandType`.
- **Omitted when absent:** `AdminSiteRemedy.Kind` and `AuditListCursor.Cursor` are left out when the server
  leaves them out.

## All SDKs

- **Site remedies:** a site remedy without a `kind` decodes as the server sends it. Rust and PHP failed on it
  before.
  - Rust `SiteRemedy.kind` is an `Option`.
  - PHP `SiteRemedy::$kind` is `?string`.
  - TypeScript and Python make it optional.
- **Audit list:** the last page's `nextCursor` decodes as `{}`.
