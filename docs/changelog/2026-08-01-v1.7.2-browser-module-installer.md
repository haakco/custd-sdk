# v1.7.2 Browser Module Installer

The browser script entrypoint now passes its own module script element to the tracker installer. ES module execution
does not provide `document.currentScript`, so the previous script-tag example could fail before loading Site config.

Custd hosts the released browser modules under `/custd-sdk/`; the script-tag example now uses that namespaced path.
The JavaScript package also accepts the Node 26 / pnpm 11 toolchain used by the current Custd frontend build.
