# v1.8.20 OAuth availability classification

The JavaScript SDK now classifies an OAuth token request rejected by the configured token endpoint
as unavailable through `CustdRequestError.unavailable`, while preserving its HTTP status,
`oauth_unavailable` code, non-retryable guidance, and original problem details.

This lets optional reporting consumers render a bounded unavailable state without parsing error
messages or converting an expected dependency condition into an application server error.
