# v1.8.27 Go time-plan request validation

The Go SDK now validates typed time-plan write requests before sending them.
Invalid identifiers, empty required fields, and malformed time values fail
locally with field-specific errors instead of reaching the Admin API.

This release includes the `v1.8.26` time-plan correction targeting changes;
the immutable `v1.8.26` tag was created before the validation fix landed.
