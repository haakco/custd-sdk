# v3.66.0 — every Custd operation in every SDK, checked against the server

Go, TypeScript, Python, PHP and Rust now each cover all 634 public Custd operations in
`contract-fixtures/api/operations.json`, the snapshot of Custd's own catalogue and OpenAPI at
`82873e00c`. Each SDK proves its coverage with a route conformance test: every operation is called
through its public method, the HTTP method, path and declared query parameters are asserted, and the
generated minimal and maximal examples are decoded. `just surface-check` compares each SDK's
coverage file with the snapshot. `just sync-api-contract ../custd` refreshes the snapshot.

This release breaks public shapes on purpose. Custd is pre-live, and the old shapes were wrong
against the server.

## Shapes corrected to the server (all SDKs)

- **Subject exports, privacy erasures and retention** had invented shapes in every SDK. They now
  match the server.
  - Subject exports: the list takes `limit`; download takes a required `scope` and returns artifact
    metadata (`objectKey`, `checksumSha256`), not a URL; cancel and force return the export.
  - Erasures take `companySlug`, and force returns its safe next action.
  - Retention policies use seconds, `get` returns the policies envelope, preview and apply return
    per-store counts, and runs are paged.
- **Lists now return envelopes:** prediction runs, outcomes, threshold events and signal sources (the
  Python versions always returned `[]` before), privacy identifier mappings, producer lists and report
  exports.
- **Offboarding receipt:** carries `requested_by_kind`, and the waiver is `{role, timestamp}`.
- **Producer provisioning:** `metadata` is removed, because the server never had it. Responses carry
  `producerSlug` and `allowedEnvironments`.
- **Null lists:** a JSON `null` list decodes as empty in every SDK. The Go server sends empty lists as
  `null`.
- **Removed:** `Admin.Schemas`, `/api/v1/admin/schemas` and prediction `rollbackVersion` called routes
  no service serves. The schema registry is reached through `Schemas` / `schemas()` on its own service.
- **About 600 field drifts** found by the new strict field checks are fixed: fields the server sends
  that SDK types lacked, and invented fields it never sends.

## New in every SDK

- Site monitoring: heartbeats, private uptime, maintenance windows, finding dismissals, incident
  acknowledgement, approval and the manual uptime check.
- Public status pages: read, subscribe, confirm and unsubscribe, with no credential.
- Monitor reports: heartbeat and private-uptime submission using the monitor's write token.
- AI owner hand-off, plus a cookie session for owner settings and consent.
- Auth-project domains, image overrides, brand logo, app links and environment releases.
- Admin users, impersonation, support access, OAuth admissions, scheduled tasks, jobs, RLS, system
  status, campaign email, notification webhooks, deliveries and destinations, email relay and error
  issues.
- The schema registry, ingest operations, cleanup plans and cleanup jobs.
- An acting-company option. It fills `companySlug` on admin routes and sends
  `X-Custd-Effective-Company` on cleanup jobs, which read the tenant only from that support-context
  header.

## Per SDK

- **Go:** `AdminUsers.List(ctx, AdminUserListOptions)`; `DataSpaces.List/Create/Revoke(…,
  parentCompanySlug)`; `Erasures.List/Get(…, companySlug)`; `Producers.RotateSecret` →
  `*ProducerSecretRotationResponse`; `GetScheduledTask` → `*ScheduledTaskDetail`;
  `ManagedAudit.ProvisionProducer(req)`; impersonation Stop and Terminate → state response.
  `RunScheduledTask` no longer returns an empty run. The webhook replay and rotate URLs are fixed.
- **TypeScript:** closed string sets are typed as unions. One normaliser turns a `null` list into `[]`
  at every list field. Offboarding fields are camelCase.
- **Python:** `read_lifecycle_fixture` is removed. Measurement admin clients live in `custd.measurement`.
  `acting_company_slug` is added.
- **PHP:** every client takes and returns readonly DTOs, `Provisioning\Client` included. The ingest
  `http_client` callback receives the HTTP method as a new last argument, so existing three-argument
  fakes keep working. `DesiredState` reads `""` and `[]` as unset, so reading a state and writing it
  back is a no-op.
- **Rust:** the crate now covers the whole admin surface, plus `SiteCollector` and
  `with_acting_company`. `download_offboarding` checks the checksum and length. Responses up to 64 MiB
  are read.

## Removed

`contract-fixtures/lifecycle/`, which froze an old branch's shapes. The generated
`contract-fixtures/api/examples/` replace it.
