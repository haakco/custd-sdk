# v3.54.0 — apps admin, Slack destinations, pushed app updates and test fakes

Adds the Apps admin surface, Slack alert destinations, pushed updates for watched app reads, an in-memory Custd for
app tests, and the social sign-in desired-state section.

- **Social sign-in (Go).** `AuthProjectDesiredState.SocialSignIn` carries the Google and GitHub providers an
  environment offers, in `shared` (Custd's provider app) or `own` mode. An own provider's `ClientSecret` is write-only
  and kept while `ClientID` is unchanged; the read-only `Status` lists the callback URLs to register. A nil section
  keeps the stored providers.
- **Pushed updates (JS/React).** Watched app reads listen on one realtime WebSocket per `AppItemsClient`
  (`/api/v1/realtime`): a pushed `item.changed` polls that read at once and the timer stays quiet while push carries
  it. The socket reconnects with backoff and resubscribes; while it is down, reads poll as before. Pass
  `webSocket` (or `null`) when you supply your own `fetch`; `startHostedApp` takes the same option.
- **Test fakes (JS/React).** `@haakco/custd-sdk/testing` exports `FakeCustd`, an in-memory Custd serving the
  discovery file, the app item, link, measurement, estimate, forecast, model, alert and meeting routes and a PKCE
  sign-in, built from the SDK's DTOs. `startHostedApp(fake.hostedAppOptions())` starts every capability: tracking and
  error capture are recorders (`fake.trackedEvents`, `fake.capturedErrors`) that touch no page globals.
  `@haakco/custd-react/testing` adds `CustdFakeHostedAppProvider`. `HostedAppOptions` gains `createTracker` and
  `startErrorCapture`, and `HostedApp.errorCapture` is typed as `HostedAppErrorCapture` (its `captureException`).
- **Slack destinations.** JS and Rust: `addAlertSlack(access, { webhookUrl })` (`add_alert_slack`) posts an app item's
  alerts to a Slack incoming webhook through `POST /api/v1/app/item/alerts/slack`; it is removed with
  `removeAlertWebhook`. Destinations carry `kind` (`webhook` or `slack`, `APP_ALERT_DESTINATION_KINDS`) and deliveries
  may have channel `slack`. Go: `NotificationWebhookCreateRequest.Kind` (`NotificationWebhookKindSlack`) adds a tenant
  Slack subscription, and `NotificationWebhookSecret` now embeds the subscription, so a create returns its `UUID` and
  `Kind`. A Slack URL is the secret: it is sealed and only a hint is read back.
- **Apps admin (Go/JS).** On `Admin.AuthProjects` / `admin.authProjects`: `CreateApp` / `createApp` (requires an
  Idempotency-Key; repeat it to finish `app_setup_incomplete`), `ListApps` / `listApps`, `GetApp` / `getApp` (latest
  release, release count, owner and share links), and `CreateAppDeployCredential` / `DeleteAppDeployCredential` for a
  CI client that can deploy only that app. `AppReleaseSummary` gains `label`.

`@haakco/custd-react` now requires `@haakco/custd-sdk` 3.54.0 or newer.
