# SDK 3.94.0 message archive

- Go, JavaScript, Python, PHP and Rust expose the signed-in tenant user's private message archive.
  The clients cover session access, batch import outcomes, paginated search, message detail,
  source deletion, and original JPEG or PNG upload and download.
- Go supports an explicit force request in `RunScheduledTaskWithOptions`. The existing
  `RunScheduledTask` continues to send a request with no body.
- Go supports the required idempotency key when creating RLS plans through
  `CreatePlanWithIdempotencyKey`.

The archive examples come from Custd's code-first OpenAPI at `15c1f0462`. The route list digest is
`298036ac74a4e6adcdbd6b5133de4811216401037d3427102dce65b8f5d893e6`.
The release retains the v3.93.0 jobs response fixture for the two optional outbox fields already
supported by that SDK release.
