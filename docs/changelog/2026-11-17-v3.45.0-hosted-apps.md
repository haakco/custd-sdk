# v3.45.0 — hosted apps

Adds the SDK half of Custd-hosted applications.

- **Browser sign-in (JS).** `BrowserSignIn` runs OAuth 2.0 authorization code with PKCE for a public client,
  stores pending state and the session in `sessionStorage`, refreshes and signs out. `signInConfigFromDiscovery`
  reads the endpoints from `/.well-known/custd.json`; the discovery `signIn.audience` is sent as the authorize
  `audience` parameter. React: `CustdSessionProvider` and `useCustdSession`.
- **Hosted app start (JS/React).** `startHostedApp` reads the discovery document and wires only the enabled
  capabilities (tracking, error capture, sign-in). React: `CustdHostedAppProvider` and `useCustdHostedApp`.
- **Forecast charts (React).** `ForecastChart`, `ArrivalHistogram` and `ConvergenceStory` with typed forecast data.
- **Release operations (Go/JS).** List, create (manifest files and routing), upload one file's raw bytes, verify and
  promote a hosted environment's releases on `admin.authProjects` / `Admin.AuthProjects`.
- **Hosting desired state (Go/JS).** The optional `hosting` section (`mode`, `capabilities`, `ingestTarget`) on the
  auth-project desired state; omitting it keeps the stored section. Status reports the derived `host`, `origin` and
  `signIn` client.
- **Fragment safety (JS).** Page-view and SPA navigation tracking never records the URL fragment, where hosted apps
  carry owner tokens; a regression test pins it.

`@haakco/custd-react` now requires `@haakco/custd-sdk` 3.45.0 or newer.
