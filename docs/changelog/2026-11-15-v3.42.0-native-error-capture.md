# v3.42.0 — native JavaScript and PHP error capture

Adds native Custd exception capture and detachable browser error/rejection listeners without a Sentry dependency.
Capture builds a privacy allowlist before sending, bounds payloads and attempts, times out, never retries and never
throws into the application. Uses the existing Custd intake, grouping and alert path. Go/Python capture is unchanged.

Server requests and browser Sites own separate keys and origin policies. See the root README for setup and limits.
