# Custd SDK v1.8.19

Version 1.8.19 adds one typed reporting availability contract across the
JavaScript, Go, Python, and PHP SDKs.

- RFC 9457 reporting errors preserve `code`, `retryability`, and `nextAction`.
- Connection failures retain their original cause and expose bounded
  unavailable state without message matching.
- Intentional caller aborts remain aborts.
- Successful reporting and data-quality trust states are unchanged.

This is a compatible additive release. Applications remain responsible for
their own HTTP status, retry, telemetry, and user-interface decisions.
