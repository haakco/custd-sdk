# v3.67.0 — data space erasure and producer signing keys

The operation snapshot is resynced from Custd `bf7276038`: 637 required operations, all covered by Go,
TypeScript, Python, PHP and Rust.

## New calls (all SDKs)

| Operation | Go | TypeScript | Python | PHP | Rust |
| --- | --- | --- | --- | --- | --- |
| `POST /api/v1/data-spaces/{slug}/erasure` | `Provisioning.DataSpaces.Erase` | `provisioning.dataSpaces.erase` | `provisioning.data_spaces.erase` | `provisioning()->eraseDataSpace` | `erase_data_space` |
| `GET /api/v1/data-spaces/{slug}/erasure` | `Provisioning.DataSpaces.GetErasure` | `provisioning.dataSpaces.getErasure` | `provisioning.data_spaces.get_erasure` | `provisioning()->getDataSpaceErasure` | `get_data_space_erasure` |
| `PUT /api/v1/producer-provisioning/{clientId}/signing-keys` | `Provisioning.Producers.SetSigningKeys` | `provisioning.producers.setSigningKeys` | `provisioning.producers.set_signing_keys` | `provisioning()->setProducerSigningKeys` | `set_producer_signing_keys` |

Erasure takes the optional `parentCompanySlug` a platform administrator names and returns
`DataSpaceErasure` (`requestUuid`, `dataSpaceSlug`, `parentCompanySlug`, `status`, `requestedAt`), with
`status` one of `requested`, `erasing`, `completed` or `failed`. Signing keys take one or two base64
Ed25519 public keys and return `clientId`, `companySlug` and `publicKeys`.

The scope templates `hosting-email-delivery` and `hosting-panel-read` have named constants in Go
(`ScopeTemplateHostingEmailDelivery`, `ScopeTemplateHostingPanelRead`), Python
(`SCOPE_TEMPLATE_HOSTING_EMAIL_DELIVERY`, `SCOPE_TEMPLATE_HOSTING_PANEL_READ`) and PHP
(`Provisioning\Client::SCOPE_TEMPLATE_HOSTING_EMAIL_DELIVERY`, `SCOPE_TEMPLATE_HOSTING_PANEL_READ`), and
join the TypeScript `scopeTemplate` union.

## Contract corrections from the resync

- Admin prediction run and outcome history take `pageSize` in Python and Rust (TypeScript already did).
- The usage export sends `format=json` in TypeScript, Python and Rust; the SDKs decode the JSON report.
- Rust: `list_report_exports` takes `limit`, `retry_scheduled_task_run` decodes the queued run, and the
  reporting-pack selector type admits the unset `""` Custd keeps in stored definitions.
