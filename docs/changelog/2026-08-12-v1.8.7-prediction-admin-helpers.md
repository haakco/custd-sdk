# Custd SDK v1.8.7

Version 1.8.7 adds tenant-scoped configurable signal prediction admin helpers
to the Go, TypeScript, Python, and PHP SDKs. The helpers cover definitions,
immutable versions, pull and push sources, run history, outcomes, evaluation,
threshold events, and lifecycle actions.

All requests carry the company slug explicitly and preserve the server's
bounded snake-case prediction contract. The release also includes the
generated TypeScript distribution artifacts and synchronized package versions.
